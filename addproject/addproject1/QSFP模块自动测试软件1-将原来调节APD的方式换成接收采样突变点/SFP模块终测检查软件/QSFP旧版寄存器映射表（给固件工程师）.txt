================================================================================
        旧版QSFP项目（SFF-8636协议）I2C寄存器映射表
        用于对接新版SFP项目（SFF-8472协议）寄存器
================================================================================

说明：
- I2C设备地址：0xA0（所有寄存器都在0xA0地址下，通过"选页"切换）
- 选页方式：向 A0h 地址127(0x7F) 写入页号，A0h的128~255字节就切换到对应页
- A0h的0~127字节是固定的"低地址区"，不随页号变化
- 数据存储在 TestResult.flash_data[1280] 数组中，共10页

================================================================================
三、GetFlashInfo() 读取顺序（数据在flash_data[]中的布局）
================================================================================

flash_data = new byte[1280];

步骤1: SelectTable(0), 读A0h 0~255     → flash_data[0..255]    256B (Page00h全页)
步骤2: SelectTable(1), 读A0h 128~255   → flash_data[256..383]  128B (Page01h)
步骤3: SelectTable(2), 读A0h 128~255   → flash_data[384..511]  128B (Page02h)
步骤4: SelectTable(3), 读A0h 128~255   → flash_data[512..639]  128B (Page03h 阈值)
步骤5: SelectTable(4), 读A0h 128~255   → flash_data[640..767]  128B (Page04h)
步骤6: SelectTable(8), 读A0h 128~255   → flash_data[768..895]  128B (APC LUT)
步骤7: SelectTable(9), 读A0h 128~255   → flash_data[896..1023] 128B (MOD LUT)
步骤8: SelectTable(10),读A0h 128~255   → flash_data[1024..1151]128B (APD LUT)

偏移计算：
- 阈值页第N字节 = flash_data[512 + N]
- APC LUT第N字节 = flash_data[768 + N]
- MOD LUT第N字节 = flash_data[896 + N]
- APD LUT第N字节 = flash_data[1024 + N]

四、关键操作流程
================================================================================

1. 上电初始化流程：
   ① setModuleDis(false) —— 给模块上电（硬件控制）
   ② 等待500ms
   ③ SetDebugPWD() —— SelectTable(0) → 写A0h 123~126 = {0xA9,0x46,0x50,0x54}
   ④ GetFlashInfo() —— 按上述顺序读所有页到flash_data[]
   ⑤ CheckTestTypeInfo() —— SelectTable(6) → 读A0h 252~255 → 判断芯片方案
   ⑥ SoftTxDis(false) —— 读A0h 86 → 清零bit0~3（打开发射）
   ⑦ DisTxRxCDR(true/false) —— 写A0h 98 = 0x00或0xFF（控制CDR）

2. DDM实时监控读取（无需选页，直接读A0h低地址区）：
   温度:  读A0h 22~23 → sbyte + byte/256
   电压:  读A0h 26~27 → uint16 × 0.0001 (V)
   RxPower: 读A0h 34~41 (ch0~3各2字节) → uint16 × 0.0001 (mW) → dBm=10*log10(mW)
   TxBias:  读A0h 42~49 (ch0~3各2字节) → uint16 × 0.002 (mA)
   TxPower: 读A0h 50~57 (ch0~3各2字节) → uint16 × 0.0001 (mW) → dBm=10*log10(mW)

3. 发射调试（Set方法，全部在Page 06h操作）：
   ① SelectTable(6)
   ② 写A0h (0xA0+ch) = APC值 (ch=0~3)  → 控制偏流/功率
   ③ 写A0h (0xA4+ch) = MOD值 (ch=0~3)  → 控制消光比
   ④ 等待30~60ms稳定
   ⑤ 读OPM实际光功率 / 读ERM消光比 → 与目标值比较 → 循环调整

4. 接收调试（Page 06h）：
   ① SelectTable(6)
   ② 写A0h (0xB4+ch) = LOS阈值 (ch=0~3)
   ③ 写A0h (0xBC+ch) = APD偏压 (ch=0~3，PIN管则不用)
   ④ 调节VOA衰减 → 读A0h (0xE8+ch*2) = Rx_ADC原始值 → 5点校准

5. 写入发射校准数据（Page 07h）：
   ① 读A0h (0xE0+ch*2) = Tx_ADC → 计算 k = (实际功率μW) / ADC
   ② SelectTable(7)
   ③ 写A0h (0x80+ch*4) = k值（4字节float）

6. 写入接收校准数据（Page 07h）：
   ① 5点测量计算校准多项式系数 c0,c1,c2
   ② SelectTable(7)
   ③ 写A0h (0x90+ch*16) = c0(4B)+c1(4B)+c2(4B)
   ④ 发送保存命令：SelectTable(6) → 写A0h 0x83 = 0x02

7. 更新温补LUT并保存（Page 8/9/10）：
   ① SelectTable(8) → 读128字节 → 修改本通道APC LUT → 写回
   ② SelectTable(9) → 读128字节 → 修改本通道MOD LUT → 写回
   ③ SelectTable(10)→ 读128字节 → 修改本通道APD LUT → 写回
   ④ SelectTable(3) → 写72字节阈值
   ⑤ 发送保存命令：SelectTable(6) → 写A0h 0x82=0x08, 0x83=0x0F
   ⑥ 等待600ms

================================================================================
五、换算公式汇总
================================================================================

温度(°C)  = (sbyte)high + low/256.0
Vcc(V)    = (high*256 + low) * 0.0001
TxBias(mA)= (high*256 + low) * 0.002
TxPower(mW)= (high*256 + low) * 0.0001
RxPower(mW)= (high*256 + low) * 0.0001
光功率dBm = 10 * Math.Log10(mW)
TOSA温度DAC电压(V) = setVal * (2.5 / 4095), setVal范围 830~1830
VON电压(V) = -setVal * (2.5 / 255)

六、需要新版SFP固件工程师提供对应地址的问题
================================================================================

旧版QSFP使用SFF-8636协议，所有寄存器在A0h地址下，通过写127字节选页访问。
新版SFP使用SFF-8472协议，标准DDM在A2h 96~105，但厂商自定义寄存器的映射
需要固件工程师确认以下问题：

1. 【调试密码】QSFP写在A0h 123~126(0x7B~0x7E)，密码是{0xA9,0x46,0x50,0x54}。
   SFP版本的调试密码写在哪里？密码值是什么？

2. 【选页机制】QSFP通过写A0h 127来切换128~255的映射页。
   SFP版本是否还有类似的选页机制？还是A2h的128~255直接是厂商自定义区？

3. 【APC/MOD/LOS/APD/VON寄存器】QSFP在Page6：
   - APC: A0h 0xA0 + ch （4通道，每通道1字节）
   - MOD: A0h 0xA4 + ch
   - LOS: A0h 0xB4 + ch
   - APD: A0h 0xBC + ch
   - VON: A0h 0xC8 + ch
   SFP单通道版本的这些DAC寄存器地址在哪里？I2C地址是A0h还是A2h？

4. 【Tx_ADC / Rx_ADC 原始值】QSFP在Page6:
   - TxADC: A0h 0xE0 + ch*2 (2字节大端)
   - RxADC: A0h 0xE8 + ch*2 (2字节大端)
   SFP版本的Tx/Rx ADC原始值读哪里？

5. 【TOSA Temp DAC / TEC控制】QSFP在Page6 A0h 0xCC~0xCD (2字节)。
   SFP版本写哪里？

6. 【校准系数区】QSFP在Page7：
   - Tx功率校准k: A0h 0x80 + ch*4 (4字节float)
   - Rx功率校准c0/c1/c2: A0h 0x90 + ch*16 (每通道12字节)
   SFP版本的校准系数存在哪里？

7. 【温补查找表】QSFP在Page8/9/10，A0h 0x80~0xFF（每页128字节）：
   - Page8 = APC LUT (32温度点×4ch)
   - Page9 = MOD LUT (32温度点×4ch)
   - Page10= APD LUT (32温度点×4ch)
   SFP版本单通道的APC/MOD/APD温补表存在哪里？每页32字节还是128字节？
