================================================================================
  新版SFP(UX3320T芯片 SFF-8472协议) 寄存器映射表 —— 与旧QSFP的15个问题答案
================================================================================

结论：TestSFPUX3320T.cs 中已经有了全部15个问题的答案！
核心变化：
  1. I2C设备地址从【0xA0】变成了【0xA2】（厂商自定义寄存器全部在A2h下）
  2. A0h只读基础信息(256字节)，A0h 0~255 = 厂商标准信息区
  3. A2h 0~95 = 标准DDM阈值+校准参数+告警标志+控制位（SFF-8472规定）
  4. A2h 96~105 = DDM实时监控值
  5. A2h 110~112 = TxDisable/LOS/告警标志控制
  6. A2h 127(0x7F) = 页选择寄存器（与QSFP机制相同，但I2C地址是A2h）
  7. A2h 128~255 = 选页区域（通过写127切换各页）

================================================================================
一、逐题答案：旧QSFP → 新SFP(UX3320T)对应关系
================================================================================

问题1【调试密码】
  旧QSFP: A0h 123~126(0x7B~0x7E), 密码={0xA9,0x46,0x50,0x54}
  新SFP : ★ A2h 0x7B(123)~0x7E(126), 密码={0xA9,0x54,0x50,0x46}
  注意：密码字节序变了！QSFP是A9-46-50-54("AFPT")，SFP是A9-54-50-46("ATPF")
  初测默认密码: FF-FF-FF-FF（写入A2h 0x7B解锁）
  写保护密码: 11-11-11-11（调试完成后写入保护）
  代码: SetDebugPWD() 中 i2c.TWI_WritePage(0xA2, 0x7B, byte_debug_pwd, 4)

问题2【选页机制】
  旧QSFP: 写A0h 127选页，切换A0h 128~255
  新SFP : ★ 写A2h 127(0x7F)选页，切换A2h 128~255（机制完全一样，只是I2C地址变A2h）
  代码: SelectTable(tbl) 中 i2c.TWI_WriteByte(0xa2, 0x7F, tbl)
  使用的页号：
    - Page 0: A2h 128~255 = 厂商信息扩展(对应A2h标准页的扩展)
    - Page 3: A2h 128~255 = ★★★调试控制寄存器页（最核心，类似QSFP的Page6）
    - Page 4: A2h 128~255 = BIAS(APC)温补LUT（105字节，压缩格式，84个温度点）
    - Page 5: A2h 128~255 = MOD温补LUT（105字节，压缩格式，84个温度点）
    - Page 6: A2h 128~255 = APD温补LUT（105字节，压缩格式，84个温度点）

问题3【APC/MOD/LOS/APD/VON寄存器】
  旧QSFP: 都在A0h Page6: APC=0xA0+ch, MOD=0xA4+ch, LOS=0xB4+ch, APD=0xBC+ch, VON=0xC8+ch
  新SFP : ★ 全部在A2h Page3（选页3后访问A2h 128~255）
    - APC(BIAS): A2h 0x8C~0x8D (128+12=140~141)，10位DAC
               0x8C = 低8位(0~255), 0x8D的bit7~5 = 高2位
               实际值 = (0x8C) | (0x8D & 0xE0) >> 5 取低2位... 实际看代码：
               SetTxApcBias中: w_val[0]=setVal, w_val[1]=register[0x8D-0x80](保留高3位bit7-5)
               写0x8C=setVal(低8位), 0x8D的bit7-5固定不变
               注意setVal>255会被截断到255，所以实际上是8位
    - MOD: A2h 0x87~0x88 (128+7=135~136)，10位DAC
           0x87 = 高8位(setVal>>2), 0x88的bit1~0 = 低2位
           实际值范围 0~1023（不是8位而是10位！）
    - LOS: A2h 0x9D (128+29=157)，单字节，0~255
    - APD: A2h 0x99~0x9A (128+25=153~154)，10位DAC
           0x99 = 高8位(setVal>>2), 0x9A的bit1~0 = 低2位
           实际值范围 0~1023
    - VON: setVON() 直接返回true —— UX3320T这个芯片方案不需要VON控制！
    - CPA: setCPA() 直接返回true —— UX3320T不需要CPA控制
  代码: 
    SetTxApcBias() → SelectTable(3) → WritePage(0xA2,0x8C,w_val,2)
    SetTxModBias() → SelectTable(3) → WritePage(0xA2,0x87,w_val,2) [10位]
    SetRxLos()     → SelectTable(3) → WriteByte(0xA2,0x9D,setVal)
    setAPD()       → SelectTable(3) → WritePage(0xA2,0x99,w_val,2) [10位]

问题4【Tx_ADC / Rx_ADC 原始值】
  旧QSFP: A0h Page6 TxADC=0xE0+ch*2, RxADC=0xE8+ch*2
  新SFP : ★ 不需要单独选页读ADC！
    - TxADC: A2h 102~103(0x66~0x67) —— 就是DDM的TxPower原始值！
    - RxADC: A2h 104~105(0x68~0x69) —— 就是DDM的RxPower原始值！
    但关键区别：读ADC前需要先切换到【外校准模式】：
      写 A2h 0xD1(209) = 0x00 → 切到外校准模式（此时A2h 102~105输出原始ADC值）
      等待300ms
      读 A2h 102~103 = TxADC 或 A2h 104~105 = RxADC
      写 A2h 0xD1 = 0x40 → 切回内校准模式（正常DDM显示模式）
  代码: GetTxADC() / GetRxADC() 中:
    SelectTable(3) → WriteByte(0xA2,0xD1,0x00) → 延时300ms 
    → ReadPage(0xA2,102,buff,2) → WriteByte(0xA2,0xD1,0x40)

问题5【TOSA Temp DAC / TEC控制】
  旧QSFP: A0h Page6 0xCC~0xCD，2字节
  新SFP : ★ UX3320T芯片代码中没有TOSA温度DAC/TEC控制！
    setVON()/setCPA()/WriteTxRxDefaultVal()都直接返回true
    说明这个UX3320T方案可能没有TEC，或者TEC是自动控制的不需要软件干预
    InitModule()中也没有设置TEC相关寄存器
  结论：SFP(UX3320T)不需要TEC控制，没有对应寄存器

问题6【校准系数区】
  旧QSFP: A0h Page7 Tx_k=0x80+ch*4(float), Rx_c0c1c2=0x90+ch*16(12B)
  新SFP : ★ 校准系数全部在A2h Page3（选页3后）
    - Tx功率校准系数: A2h 0xBC~0xBF (128+60=188~191)，4字节
      格式：kk[0]=整数部分, kk[1]=小数部分(*256), 0x00, 0x00
      k = kk[0] + kk[1]/256.0（定点数，不是IEEE float！）
      写入代码: writeByte[0]=(byte)fk; writeByte[1]=(byte)((fk-writeByte[0])*256);
    - Rx功率校准系数: A2h 0xC0~0xCF (128+64=192~207)，16字节
      分段线性校准（3段，不是5次多项式！）:
        0xC0~0xC3: 段0: k(2字节定点) + b(2字节int16大端)
        0xC4~0xC7: 段1: k(2字节定点) + b(2字节int16大端)
        0xC8~0xCB: 段2: k(2字节定点) + b(2字节int16大端)
        0xCC~0xCF: ADC分界点: adc1(2字节uint16大端) + adc2(2字节uint16大端)
      注意：旧QSFP用5点多项式(c0~c4)，新SFP用3段线性拟合(k,b各3组+2个ADC分界点)
      另外A2h 0xD1寄存器(bit7)控制内/外校准模式
  代码:
    WriteTxCalData() → SelectTable(3) → WritePage(0xA2,0xBC,writeByte,4)
    WriteRxCalData() → SelectTable(3) → WritePage(0xA2,0xC0,writeByte,16)

问题7【温补查找表】
  旧QSFP: A0h Page8/9/10，每页128字节，32温度点×4通道，原始uint8格式
  新SFP : ★ 在A2h的Page4/5/6（选页后访问128~255）
    - Page4: BIAS(APC) LUT, 105字节（压缩格式）→ 对应84个温度点（每2°C一个点，-40°C~+127°C）
    - Page5: MOD LUT, 105字节（压缩格式）→ 同上
    - Page6: APD LUT, 105字节（压缩格式）→ 同上
    ★ 重要变化：
      1. 温度点密度变了：QSFP是32个点(每5°C), SFP是84个点(每2°C)！
      2. 数据格式变了：不是直接存uint8/uint16，而是10位值的压缩打包：
         每5个字节存储4个uint10值(每个0~1023):
           byte[k+0] = val[i+0] >> 2
           byte[k+1] = (val[i+0] & 0x03) << 6 | val[i+1] >> 4
           byte[k+2] = (val[i+1] & 0x0F) << 4 | val[i+2] >> 6
           byte[k+3] = (val[i+2] & 0x3F) << 2 | val[i+3] >> 8
           byte[k+4] = val[i+3] & 0xFF
         即5B打包4个10位值，21组×5B=105B → 84个温度点
      3. 单通道，不需要ch索引
    temp_index计算: index = (int)((temp + 40) / 2.0f)  （每2°C一个点）
    代码: SaveTxDataAfterDebug()中i=0;for(k=0;k<105;k+=5){打包4个10位值到5字节}

问题8【告警阈值】
  旧QSFP: A0h Page3 0x80~0xC7(72字节)自定义
  新SFP : ★ A2h 0~55(0x00~0x37) —— 标准SFF-8472阈值区域（40字节）
    直接遵循SFF-8472标准定义，地址固定：
    - 0~1:   Temp High Alarm (s16, 单位1/256°C)
    - 2~3:   Temp Low Alarm
    - 4~5:   Temp High Warning
    - 6~7:   Temp Low Warning
    - 8~9:   Vcc High Alarm (u16, ×0.0001V)
    - 10~11: Vcc Low Alarm
    - 12~13: Vcc High Warning
    - 14~15: Vcc Low Warning
    - 16~17: Bias High Alarm (u16, ×0.002mA? 注意SFP是/500.0即×0.002)
    - 18~19: Bias Low Alarm
    - 20~21: Bias High Warning
    - 22~23: Bias Low Warning
    - 24~25: TxPower High Alarm (u16, ×0.0001mW)
    - 26~27: TxPower Low Alarm
    - 28~29: TxPower High Warning
    - 30~31: TxPower Low Warning
    - 32~33: RxPower High Alarm (u16, ×0.0001mW)
    - 34~35: RxPower Low Alarm
    - 36~37: RxPower High Warning
    - 38~39: RxPower Low Warning
    A2h 56~94(0x38~0x5E) = 扩展校准参数(39字节，ex_cal数组)
    A2h 95(0x5F) = checksum（0~94字节校验和）
    GetDDMThresholds()直接读A2h 0~39解码
    CheckThresholdsInfo()检查threshold[56B]+ex_cal[39B]在A2h 0~94

问题9【Flash保存命令】
  旧QSFP: A0h Page6 0x83=0x02/0x11, 0x82/0x83=0x08/0x0F
  新SFP : ★ UX3320T是【自动保存】或者【不需要显式保存命令】！
    WritSaveCmd() 直接 return true; —— 没有写任何保存命令
    但有一个特殊操作：写完数据后需要【软件复位UX3320T】
    软件复位密码：向A2h 0x7B写5个字节: {0x4A,0x36,0x58,0x6E,0x7B} = "J6Xn{"
    复位后等待1000ms
    代码: SoftResetUX3320T() → WritePage(0xA2,0x7B,reset_pwd,5)
    注意：写完校准数据或LUT后，需要计算并写入EEPROM校验和到 A2h Page3 0xDB(219)
      checksum = sum(biasLUT[0..104]) + sum(modLUT[0..104]) + sum(apdLUT[0..104])
               + sum(regTbl3[0x81..0xA0-0x80]) + sum(regTbl3[0xA2..0xD2-0x80])
      写 A2h 0xDB = checksum
    代码: GetEEPROMcheckSumDB() / SaveRxDataAfterDebug()

问题10【芯片ID/方案识别】
  旧QSFP: A0h Page6 0xFC~0xFF (4字节)
  新SFP : ★ A2h Page3 0xF5~0xFB (128+117=245~251)，7字节ASCII
    Chip ID = "UX33200" (0x55,0x58,0x33,0x33,0x32,0x30,0x30)
    代码: CheckTestTypeInfo() → SelectTable(3) → ReadPage(0xA2,0xF5,readChipID,7)
    额外：终测时检查 A2h Page3 0xEF~0xF0 的bit7~2必须为0(EEPROM状态指示)

问题11【Tx_EN/TEC控制】
  旧QSFP: A0h Page6 0xFA写0x66启动TEC, A0h 86控制TxDisable
  新SFP :
    - TxDisable: A2h 110(0x6E) bit6
      1=关发射(tx_dis), 0=打开发射(tx_en)
      代码: SoftTxDis() → ReadByte(0xA2,110) → set/clear bit6 → WriteByte(0xA2,110)
      注意：QSFP是bit0~3控制4通道，SFP只有bit6控制单通道
    - TEC控制: UX3320T没有TEC控制代码！InitModule()中没有相关操作

问题12【温补LUT使能】
  旧QSFP: A0h Page6 0x80 (0x00关, 0x01开)
  新SFP : ★ 在A2h Page3
    - BIAS/MOD LUT使能: A2h 0x82(130)
      写register[0x82-0x80]的高2位(bit7~6)控制
      使能: 直接写register[0x82-0x80]原值（数据库配置好的值，含bit7-6=11）
      禁用: value & 0x3F（清除bit7~6）
    - APD LUT使能: A2h 0x98(152)
      bit3控制：0=使能APD LUT, 1=禁用APD LUT
      注意和直觉相反：0是enable, 1是disable！
    代码: TxTempLookupTableCtrl(enable)

问题13【Fibertop内部SN/PN数据】
  旧QSFP: A0h Page4 128~255
  新SFP : ★ 分两部分：
    - 标准SN/PN/VN(DateCode): 在A0h 0~255中
      VN(厂商名): A0h 20~35 (16字节ASCII) → flash_data[20]开始
      PN(型号):   A0h 40~55 (16字节ASCII) → flash_data[40]开始
      SN(序列号): A0h 68~83 (16字节ASCII) → flash_data[68]开始
      DateCode:   A0h 84~91 (8字节ASCII)  → flash_data[84]开始
      代码: GetFlashInfo() → ReadPage(0xa0,0,readbuffer,256)
    - Fibertop内部流水号(Fsn): 在A2h Page4 0xF0~0xF4(128+112=240~244)
      5字节uint64大端整数
      代码: GetFlashInfoDebug()中 flash_data[640+112+0..4] (Page4偏移112=0x70)
      即 A2h Page4 0xF0(240)~0xF4(244)

问题14【CDR控制】
  旧QSFP: A0h 98 (0x00关, 0xFF开)
  新SFP : DisTxRxCDR() 直接 return true —— UX3320T不需要CDR控制（可能没CDR）
  InitModule()中A2h 0xA1写0x12, 0x86写0x00等配置寄存器，但不是CDR开关

问题15【Tx-PE等其他参数】
  旧QSFP: Page6 0xED(TX-PE), 0xAC(TX-CPA)等
  新SFP :
    - TX-PE: WriteTxRxDefaultVal()直接return true —— 不需要
    - TX-CPA: setCPA()直接return true —— 不需要
    - 但有一些额外的初始化配置寄存器(在Page3):
      InitModule()中:
        A2h 0xA1 = 0x12 (bit7=0,bit4=0,bit1=1,bit0=0)
        A2h 0x86 = 0x00 (bit7=0,bit6=0)
        A2h 0x96 = 0x02
        A2h 0x97 = 0x00
        A2h 0x9B = 0x01
        A2h 0xD1 = 0x40 (bit6=1，内校准模式)
      PW1密码位置: A2h Page3 0xD3~0xD6 (4字节)
      PW2调试密码位置: A2h Page3 0xD7~0xDA (4字节)
      EEPROM校验和: A2h Page3 0xDB (1字节)
      EEPROM状态: A2h Page3 0xEF~0xF0 (终测检查bit7~2=0)
      内外校准切换: A2h Page3 0xD1 (bit7=0x40为内校准,0x00为外校准读ADC)

================ A2h 选页区域（128~255，通过写A2h 127选页）================

★ Page 0（写127=0）: A2h 0~255整体映射
  128~255 = A2h扩展厂商数据区(256字节)
  代码中GetFlashInfo()读A2h 0~256整体存入flash_data[256~511]

★ Page 3（写127=3）: ★★★调试控制寄存器页（最核心！）
地址(A2h)   偏移  长度  读写   功能
──────────────────────────────────────────────
80(128)     0     2    读写   初始化标志: 0xAA,0x00=已初始化

86(134)     6     1    读写   InitModule配置: 写0x00(bit6/7=0)
87~88(135~136) 7 2  读写   ★MOD寄存器(10位DAC): 0x87=高8位, 0x88低2位=bit1~0
88                    注意  bit7~5保留
8C~8D(140~141) 12 2 读写   ★APC/BIAS寄存器(主要8位): 0x8C=DAC值(0~255), 0x8D高3位保留
96(150)     22    1    读写   InitModule配置: 写0x02
97(151)     23    1    读写   InitModule配置: 写0x00
98(152)     24    1    读写   APD LUT使能: bit3=0使能APD LUT, bit3=1禁用
99~9A(153~154) 25 2 读写   ★APD寄存器(10位DAC): 0x99=高8位, 0x9A低2位=bit1~0
9B(155)     27    1    读写   InitModule配置: 写0x01
9D(157)     29    1    读写   ★LOS阈值寄存器(单字节0~255)
A1(161)     33    1    读写   InitModule配置: 写0x12
BC~BF(188~191) 60 4 读写   ★Tx功率校准系数(k定点数):
                              BC=k整数部分, BD=k小数部分(*256), BE=00, BF=00
C0~CF(192~207) 64 16 读写  ★Rx功率校准系数(3段线性):
                              C0~C1: 段0斜率k(定点), C2~C3: 段0截距b(int16大端)
                              C4~C5: 段1斜率k(定点), C6~C7: 段1截距b(int16大端)
                              C8~C9: 段2斜率k(定点), CA~CB: 段2截距b(int16大端)
                              CC~CD: ADC分界点1(u16大端), CE~CF: ADC分界点2(u16大端)
D1(209)     81    1    读写   ★内外校准模式切换:
                              0x00=外校准模式(此时A2h 102~105=ADC原始值)
                              0x40=内校准模式(正常DDM, bit6=1)
D3~D6(211~214) 83 4  读写   PW1密码区(4字节)
D7~DA(215~218) 87 4  读写   ★PW2调试密码区(4字节, =byte_debug_pwd)
DB(219)     88    1    读写   ★EEPROM校验和
EF(239)     111   2    只读   EEPROM状态指示(终测bit7~2必须=0)
F5~FB(245~251) 117 7 只读   ★Chip ID芯片识别码(ASCII"UX33200")

★ Page 4（写127=4）: ★BIAS(APC)温补LUT
  A2h 128~255 = 105字节（压缩格式，84个温度点，每2°C一个点）
  5字节打包4个uint10值(0~1023)
  对应温度范围: -40°C ~ +127°C (84点×2°C-40=128°C)
  flash_data偏移: 640开始

★ Page 5（写127=5）: ★MOD温补LUT
  A2h 128~255 = 105字节（压缩格式同BIAS）
  flash_data偏移: 768开始
  ★ Fsn(Fibertop内部流水号)在Page4的0xF0~0xF4 (240~244)

★ Page 6（写127=6）: ★APD温补LUT
  A2h 128~255 = 105字节（压缩格式同BIAS）
  flash_data偏移: 896开始

================================================================================
三、DDM换算公式（SFP UX3320T）
================================================================================

温度(°C)   = (sbyte)readbuffer[0] + readbuffer[1]/256.0
Vcc(V)     = (high*256 + low) / 10000.0
TxBias(mA) = (high*256 + low) / 500.0         ← 注意与QSFP相同(/500=×0.002)
TxPower(dBm) = 10*log10( (high*256+low)/10000.0 )
RxPower(dBm) = 10*log10( (high*256+low)/10000.0 )
TxADC/RxADC = (high*256 + low)  —— 读前需写0xD1=0x00切外校准模式

================================================================================
四、flash_data[]内存布局（共1024字节）
================================================================================

flash_data = new byte[1024] (TestResult.flash_data_len=1024)

0~255:    A0h 0~255          → 模块基本信息(256B)
256~511:  A2h 0~255(Page0)   → DDM阈值+校准+控制+扩展(256B)
512~639:  A2h Page3 128~255  → 调试控制寄存器(128B,实际有效93B)
640~767:  A2h Page4 128~255  → BIAS LUT(128B,实际有效105B) + Fsn在偏移112处
768~895:  A2h Page5 128~255  → MOD LUT(128B,实际有效105B)
896~1023: A2h Page6 128~255  → APD LUT(128B,实际有效105B)

================================================================================
五、关键操作流程（SFP UX3320T）
================================================================================

1. 上电初始化:
  ① setModuleDis(false) 给模块上电
  ② 等待500ms
  ③ SetDebugPWD():
     - 写A2h 0x7B = {0xA9,0x54,0x50,0x46} (调试密码)
     - 延时100ms
     - SelectTable(3)
     - 读A2h 0x80~0x81 → 应=0xAA,0x00表示进入调试模式成功
     - 如果失败且是初测: 写A2h 0x7B = {0xFF,0xFF,0xFF,0xFF}(默认密码)再试
  ④ GetFlashInfo(): 读A0h 0~255 + A2h 0~255(Page0) → flash_data[0~511]
  ⑤ GetFlashInfoDebug(): 依次选Page3/4/5/6读128字节 → flash_data[512~1023]
     读完后写保护密码{0x11,0x11,0x11,0x11}到A2h 0x7B
     再重新读A2h 0~95更新flash_data[256~351]
  ⑥ CheckTestTypeInfo(): SelectTable(3) → 读A2h 0xF5~0xFB == "UX33200"
  ⑦ SoftTxDis(false): 读A2h 110 → 清bit6 → 写回 → 打开发射
  ⑧ InitModule()(仅初测):
     - SelectTable(3)
     - 读A2h 0x80~0x81，若是0xAA,0x00则说明已初始化过返回false
     - 配置初始化寄存器:A1=0x12, 86=0x00, 96=0x02, 97=0x00, 9B=0x01, D1=0x40
     - 从数据库加载register[93B]+bias/mod/apd LUT默认值
     - 写入Page4/5/6的LUT(105B压缩格式)
     - 写入Page3的register[93B](含校验和在0xDB)
     - SoftResetUX3320T() → 写A2h 0x7B={0x4A,0x36,0x58,0x6E,0x7B}复位
     - 等待1000ms

2. DDM实时监控（不选页，直接读A2h低地址区）:
  GetDDMAnalogValues(): ReadPage(0xA2,96,buff,10) → 一次性读10字节
  包含Temp/Vcc/Bias/TxPwr/RxPwr全部5个量

3. 发射调试:
  ① SelectTable(3)
  ② SetTxApcBias(value): 写A2h 0x8C=value, 0x8D保留高3位 → 延时400ms
  ③ SetTxModBias(value): 写A2h 0x87=(value>>2), 0x88低2位=(value&0x03) → 延时100ms
     ★ MOD是10位DAC(0~1023)，不是8位！
  ④ 读OPM/ERM → 循环调整
  ⑤ TxBias监控: GetTxBias()读A2h 100~101 → /500.0mA

4. 接收调试:
  ① SelectTable(3)
  ② SetRxLos(value): 写A2h 0x9D = value
  ③ setAPD(value): 写A2h 0x99=(value>>2), 0x9A低2位=(value&0x03) → 10位DAC
  ④ GetRxADC():
     - 写A2h 0xD1=0x00(外校准模式) → 等300ms
     - 读A2h 104~105 = RxADC原始值
     - 写A2h 0xD1=0x40(切回内校准模式)

5. 写入发射校准:
  ① SelectTable(3)
  ② GetTxADC()获取原始ADC值(切外校准读A2h 102~103)
  ③ 计算k = (实际功率μW) / ADC = (10^(dBm/10)*10000) / ADC
  ④ 写A2h 0xBC~0xBF = {k整数, k小数*256, 0x00, 0x00} (定点数，不是float!)

6. 写入接收校准（3段线性，不是5点多项式！）:
  ① 从5点校准数据计算3段线性k,b值和2个ADC分界点
  ② SelectTable(3)
  ③ 写A2h 0xC0~0xCF = 16字节(3组k,b + 2个ADC分界点)

7. 保存调试数据:
  ① SaveTxDataAfterDebug():
     - 计算84温度点BIAS/MOD的uint10值数组(每2°C一个点)
     - 打包成5B/4值的压缩格式(每LUT 105字节)
     - 写A2h 0~95 = threshold[40B]+ex_cal[39B]+checksum[1B]
     - SelectTable(4) → 写bias LUT 105B到A2h 0x80
     - SelectTable(5) → 写mod LUT 105B到A2h 0x80
     - SelectTable(6) → 读apd LUT保持不变
     - TxTempLookupTableCtrl(true) → 开启温补
     - 计算EEPROM校验和 → 写A2h Page3 0xDB = checksum
     - 写PW2调试密码到A2h Page3 0xD7~0xDA
  ② SaveRxDataAfterDebug():
     - GetEEPROMcheckSumDB()计算并写入校验和
     - WritSaveCmd()→return true(无需额外保存命令，UX3320T自动保存)
  ③ 注意：写完重要数据后需要SoftResetUX3320T()复位芯片

================================================================================
六、QSFP→SFP 移植需要修改的核心代码点汇总
================================================================================

1. 所有I2C设备地址: 0xA0 → 0xA2（厂商自定义寄存器全在A2h）
   例外：A0h 0~255是标准信息区(SN/PN/VN等)，保持读A0h不变

2. DDM读取地址:
   温度: A0h 22~23 → A2h 96~97
   Vcc:  A0h 26~27 → A2h 98~99
   TxBias: A0h 42+ch*2 → A2h 100~101（单通道无ch偏移）
   TxPower: A0h 50+ch*2 → A2h 102~103
   RxPower: A0h 34+ch*2 → A2h 104~105
   TxBias换算: ×0.002 → /500.0（一样）
   换算公式中TxPower/RxPower: ×0.0001mW → /10000.0（一样）

3. TxDisable:
   A0h 86 bit0~3 → A2h 110 bit6（单通道）
   Rx_LOS: A0h 3 bit0~3 → A2h 110 bit1

4. 选页寄存器:
   A0h 127 → A2h 127(0x7F)（机制一样，地址变A2h）

5. 调试密码:
   地址: A0h 123~126 → A2h 123~126(0x7B~0x7E)
   密码: {A9,46,50,54} → {A9,54,50,46}（字节序变了）

6. 调试寄存器全部从A0h Page6 → A2h Page3:
   APC:  A0h 0xA0(Page6) → A2h 0x8C~0x8D(Page3)，保持单字节
   MOD:  A0h 0xA4(Page6) → A2h 0x87~0x88(Page3)，变成10位DAC！
   LOS:  A0h 0xB4(Page6) → A2h 0x9D(Page3)，单字节
   APD:  A0h 0xBC(Page6) → A2h 0x99~0x9A(Page3)，变成10位DAC！
   VON:  直接return true（不需要）
   CPA:  直接return true（不需要）
   TOSA_Temp: 不需要（UX3320T无TEC）
   Tx_EN/TEC: 不需要

7. ADC读取方式完全变了:
   旧: 选Page6，直接读A0h 0xE0/0xE8
   新: 选Page3，写A2h 0xD1=0x00切外校准→等300ms→读A2h 102/104→写0xD1=0x40切回

8. 校准系数:
   Tx: A0h Page7 0x80(float) → A2h Page3 0xBC(定点数2B+2B零)
   Rx: A0h Page7 0x90(c0~c4多项式12B+额外) → A2h Page3 0xC0(3段线性16B)
   ★ 校准算法需要重写：5点多项式 → 3段线性拟合

9. 温补LUT:
   页: Page8/9/10 → Page4/5/6
   格式: 128B原始uint8 → 105B压缩(5B/4个uint10)
   温度点: 32点(每5°C) → 84点(每2°C)
   ★ LUT数据格式和温度分辨率完全变了！打包/解包函数需要重写

10. 告警标志:
    A0h 3~24 → A2h 112~117(标准SFF-8472标志位)

11. 芯片ID:
    A0h Page6 0xFC~0xFF(4B) → A2h Page3 0xF5~0xFB(7B ASCII "UX33200")

12. Flash保存:
    旧: 写A0h Page6 0x82/0x83保存命令
    新: ①计算写0xDB校验和 ②写完后SoftResetUX3320T(写特殊5字节密码复位)
    WritSaveCmd()是空操作(return true)，不需要显式保存命令

13. 阈值:
    A0h Page3 0x80~0xC7(72B自定义) → A2h 0~39(40B标准SFF-8472)+ex_cal[39B]
    地址0就是标准阈值起点，不需要选页

14. CDR控制:
    DisTxRxCDR()直接return true（UX3320T不需要CDR控制）

15. flash_data长度:
    1280字节 → 1024字节 (TestResult.flash_data_len=1024)

16. VN/PN/SN/DateCode:
    VN: A0h Page0 148~163 → A0h 20~35
    PN: A0h Page0 168~183 → A0h 40~55
    SN: A0h Page0 196~211 → A0h 68~83
    DateCode: A0h Page0 212~219 → A0h 84~91

17. 软件复位:
    新增SoftResetUX3320T()功能
    写A2h 0x7B = {0x4A,0x36,0x58,0x6E,0x7B} → 等待1000ms
